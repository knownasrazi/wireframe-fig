## Preview

> Wireframes in cream wire. - built for vibe coders and web developers who ship.

## Stack

- Vite + React + TypeScript
- Tailwind CSS (cream palette)
- Biome for lint and format

## Get started

```bash
git clone https://github.com/knownasrazi/wireframe-fig.git
cd wireframe-fig
bun install
bun run dev
```
wireframe-fig/
  src/
    App.tsx      # app shell
    index.css    # cream tokens
  index.html
  vite.config.ts
  package.json
```

## Cream tokens

Cream, stone, and ink - low contrast, high taste.
